Mini Tags

Tags extracted by default from a mif3 low-overhead SlimHEIF 'mini' box. More tags (flags, etc.) are extracted from the mini header when the Unknown option is used. The family 1 group name for these tags is "Mini".

When writing, by default new EXIF and XMP blocks are not compressed unless compressed data already exists, but EXIF and XMP are compressed if the API Compress option is set to 1, or uncompressed if set to 0. Compress::Zlib is required to enable this feature.

ExifTool Version History

RSS feed: https://exiftool.org/rss.xml

Note: The most recent production release is Version 13.55. (Other versions are considered development releases, and are not uploaded to MetaCPAN.)

Nov. 10, 2026 - Version 13.63
  • Decode more Pentax tags (thanks Rich Adams)
  • Changed name of one of the new Canon tags
  • Fixed typo in new Mini tag name
  • Fixed bug introduced in 13.62 when reading GIF extensions
Nov. 9, 2026 - Version 13.62
  • Added read/write support for low-overhead mif3 SlimHEIF 'mini' metadata, including support for compressed EXIF and XMP (github #503)
  • Added ability to delete C2PA metadata from GIF images (github #515)
  • Decode more Canon tags (thanks Peter Wem github #510, #511, #512)
  • Decode more Red tags (github #443)
  • Fixed crash introduced in 13.60 when trying to delete then recreate EXIF in a Xiaomi HEIC file (github #485)
Nov. 5, 2026 - Version 13.61
  • Added a new Olympus CameraType (thanks Herb github #502)
  • Added arg_files/audio2itemlist.args to the distribution (github #497)
  • Decode some more Canon tags (github #505, #506, #507)
  • Recognize the SlimHEIF mif3 file type (github #503)
  • Changed DJI NRSetting tag name to NoiseReduction for consistency
  • Patched issue where a corrupted FLIF file could cause a hang (github #500)
  • Patched to avoid backward seek on empty QuickTime atom (github #482)
  • Patched compatibility issue with Sony Imaging Edge applications when writing ARW files (github #465)
  • Patched a few places where corrupt metadata could result in excessive memory usage
  • Fixed performance issue when using -j on a file with large binary tag values (github #496)
Oct. 28, 2026 - Version 13.60
  • Added definitions for the new Exif for XMP tags
  • Added support for the Pentax KF (thanks Karsten Geiselmann)
  • Added warning for possibly corrupted IFD if the first entry has a bad format
  • Added a few new FujiFilm AdvancedFilter values (github #454)
  • Added some new FujiFilm GrainEffectRoughness values (github #455)
  • Added missing values for EXIF NoiseReduction (github #416)
  • Added some new Canon and Nikon LensIDs (github #415, #418, #486)
  • Added support for reading RED XE R3D files (github #443)
  • Decode some new Canon tags (github #400, #464, #488, #490)
  • Decode a new tag for the Ricoh GR IV Monochrome, and add a few other values
  • Decode a few new Garmin FIT tags
  • Decode a new Nikon NCTG tag (thanks Wade Tregaskis)
  • Decode more DJI protobuf tags (thanks Alexey Dogaev)
  • Decode timed GPS for more DJI models (github #412, #436, #440)
  • Decode HEIC stereo image information (github #480)
  • Decode timed GPS for another dashcam (github #487)
  • Decode more tags for the Ricoh GR IV Monochrome (github #461)
  • Decode Olympus WhiteBalanceFineTune (github #462)
  • Decode ShutterCount for some firmware versions of the Canon EOS RP
  • Extract APP2 PreviewImage from EXIF data of Xiaomi HEIC files
  • Improved handling of Canon CameraInfo firmware versions
  • Relaxed PDF parsing to accept some questionable XREF tables (github #481)
  • Disambiguate Garmin FIT developer messages which result in the same tag name (github #463)
  • Update for Nikon Z6iii firmware 2.0 (thanks Warren Hatch)
  • Lowered priority of Composite:ISO for Canon MP4 videos (github #431)
  • Removed goto statements from Geotag.pm to make JavaScript translation easier
  • Patched to fix html injection issue in -htmlDump feature (github #444)
  • Patched to recognized LigoGPS trailer with different marker (github #470)
  • Patched to avoid hang when using -stay_open and piping arguments from stdin if the pipe is closed (github #458)
  • Patched to fix conversion of ModelReleaseYear for new Sony ILCE-1M2 firmware
  • Patched potential deep recursion when reading malformed PGF file
  • Patched potential crash issue when reading GM PDR metadata
  • Fixed issue where extraneous non-EXIF APP segments weren't handled properly in the EXIF data of Xiaomi HEIC files (github #485)
  • Fixed potential "pointer references previous directory" error when processing some PNG images (github #453)
  • Fixed problem where Samsung HEIC motion-photo images weren't recognized as motion photo after editing with ExifTool ('sefd' atom must come last). Re-editing with this version of ExifTool will repair any damaged files
  • Fixed failed Garmin test on some systems (github #423)
  • Fixed hang issue when reading truncated Geolocation database (github #495)
  • API Changes:
    • Added QuickTimeUndLang option (github #451)
May 27, 2026 - Version 13.59
  • Security update
  • Added NewUUID Extra tag (thanks Daniel Dumitriu, github #421)
  • Added a new Canon RF lens (thanks Norbert Wasser)
  • Added config_files/novelty.config to the distribution (github #422)
  • Decode tags from the Sony ILCE-7RM6 (thanks Jos Roost)
  • Decode a new FujiFilm tag (thanks Iliah Borg)
  • Decode a few more DJI protobuf tags
  • Decode a new Ricoh Pentax tag
  • Issue Error instead of Warning when writing XMP with some problems which could cause loss of data
  • Improved error message when reading wrongly encoded CSV or JSON file
  • Enhanced -config option to allow piped input with "-config -"
  • Enhanced -validate option to do more strict checking of EXIF-for-XMP tags
  • Patched -sort option avoid inconsistent output ordering of same-named tags
  • Patched Composite SubSec date/time tags to specify the EXIF group for the SubSec and OffsetTime tags upon which they are based (avoids non-standard XMP tags from being incorrectly used here)
  • Fixed bug in -diff feature when finding differences for specific tags and a specified tag was missing from the source file
May 5, 2026 - Version 13.58
  • Added a few new Nikon Z lenses (thanks Warren Hatch)
  • Added a few new QuickTime MajorBrand values (thanks Herb)
  • Added a new RAFCompression value
  • Added undocumented -eh option (alias for -E/-escapeHTML)
  • Decode timed GPS from INNOVV N2 TS videos
  • Improved decoding of Canon ColorData for some models (thanks Iliah Borg)
  • Changed the name of the RAFVersion tag to FirmwareVersion
  • Removed conversion for Garmin FIT DeviceIndex values
  • Properly parse XML CDATA and comment sections
  • Fixed issue which could cause failed Garmin test on some systems
Apr. 17, 2026 - Version 13.57
  • Added print conversions for Garmin FIT enum tags
  • Decode a number of undocumented Garmin FIT tags
  • Reverted XML patch of 13.56 which broke structured output for XMP files with an XML header
Apr. 15, 2026 - Version 13.56 - "Exif 3.1"
  • Added new tags of the Exif 3.1 specification
  • Added ability to geotag directly from any supported file(s) containing GPS
  • Added read support for Garmin FIT files, and the ability to use them with the -geotag option
  • Added a new Panasonic AFAreaMode (thanks Andrew)
  • Decode maker notes from newer FLIR cameras (github #408)
  • Improved config_files/local_time.config to add LocalTag UserParam feature
  • Updated Compression value re-purposed by GoPro (github #411)
  • Allow a few more different characters in the Windows -progress title string
  • Avoid trying to return structured information from XML files
  • Patched bug when reading QuickTime MTDT metadata (thanks Thurein Oo)
  • API Changes:
    • Enhanced GetValue so input tag name is no longer case sensitive
Apr. 7, 2026 - Version 13.55 (production release)
  • Added a few new Windows LNK GUID values
  • Extract more unknown information from QuickTime metadata tracks
  • Improved config_files/local_time.config to preserve sub seconds
  • Improved lens identification logic for Canon cameras in the case where the maker notes are missing
Apr. 1, 2026 - Version 13.54
  • Security update
  • Added a new PentaxModelID
  • Decode timed GPS from another DJI model
  • Decode more information from Apple live photo videos
  • Updated DICOM tags to 2026b specification
  • Patched to fix failed tests on Windows (was a bug in the tests)
  • Patched to allow spaces in Windows title strings
Mar. 19, 2026 - Version 13.53
  • Security update (Windows only)
  • Added ability to read FileCreateDate (btime) on Linux systems (requires File::StatX)
  • Added a bunch more Sony lenses (thanks Jos Roost)
  • Added warnings for possibly malicious or corrupted LNK files (github #401)
  • Decode more information from LNK files
  • Decode timed GPS from Kenwood DRV-A510W MP4 videos
  • Fixed possible "undefined value" runtime warnings when reading torrent and WPG files (thanks Raf)
  • Fixed issue which could result in an "uninitialized value" runtime error when parsing corrupted CBOR information

  • Added a few more Canon FlashModel values and decode FlashModel for the 5DmkII (thanks Peter Wem, github #390)
  • Added a new Canon LensType (github #395)
  • Added some missing file attribute bits to two of the new LNK tags
  • Decode internal serial number for the 5DmkII (thanks Peter Wem, github #398)
  • Decode another OwnerName for the 5DmkII (thanks Peter Wem, github #397)
  • Decode some timed GPS for a couple of new DJI drones
  • Enable WindowsLongPath by default only if Win32::API is available
  • Renamed the Pentax K3III AFInfo tag to AFInfoK3III

  • Decode some new Canon tags (thanks Peter Wem, github #389, #390, #393)
  • Decode some new Nikon tags

  • Fixed bug generating the default-language version of QuickTime:LocationInformation (github #391)
